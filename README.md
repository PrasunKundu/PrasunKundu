### [Page Roast](https://page-roast-psi.vercel.app) — AI Landing Page Analyzer

> *Full-stack AI SaaS. Built and shipped solo.*

Captures live screenshots via Browserless.io → routes through Gemini 1.5 Flash Vision API → returns a structured conversion audit with a score, pass/fail analysis, and prioritized fixes.

**Stack:** `Next.js 15` `TypeScript` `Gemini 1.5 Flash` `Supabase` `Upstash Redis` `Vercel`

### Architecture Highlights

* Serverless App Router backend
* Structured JSON output parsing
* Prompt chaining workflows
* Sliding-window rate limiting
* Zero-cost SaaS infrastructure
